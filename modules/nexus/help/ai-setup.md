The AI features need your own AI key: TimeGrow is free, and any AI cost is between you and the provider. In Settings > AI, add a configuration with the provider (OpenAI, Anthropic or Google), the model and your API key, test it and make it the default. Voice Entry and Receipt Reading can each use the default or a different configuration.

Without a key, the voice chat asks each question one at a time and receipts are typed in by hand.
