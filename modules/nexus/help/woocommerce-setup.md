TimeGrow invoices through WooCommerce, which is free; it needs no key. Install and activate the WooCommerce plugin first (Plugins > Add New, search "WooCommerce").

Then open Settings > WooCommerce Integration in TimeGrow and turn on what you use: clients (use the clients' WooCommerce billing details), products (each project gets its own hidden, virtual product, created automatically the first time it is billed and priced at the project's rate), and decimal quantities (so 1.5 hours is billed as 1.5, not rounded).

After that, bill time from Process Time: it turns billable time into WooCommerce orders. To send the invoices through PayPal, set up PayPal too.
