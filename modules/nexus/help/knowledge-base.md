Settings > Knowledge Base lists the help topics the voice assistant answers "how do I…?" questions from. Edit a topic to change what it says, add your own topics, or hide one the assistant should not use. Built-in topics you edit can be reset to the original text.

Use Try a question to see which topics would answer a question, as an administrator or as a team member. Changes made here are kept when TimeGrow is updated.
